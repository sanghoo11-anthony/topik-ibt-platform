# Global TOPIK I · II Smart IBT Platform

전 세계 한국어 학습자를 위한 **TOPIK I (1~2급) · TOPIK II (3~6급) 통합 스마트 IBT 모의고사 & 다국어 학습 플랫폼**입니다.

- **🌐 라이브 웹 홈페이지 주소 (GitHub Pages)**: [https://sanghoo11-anthony.github.io/topik-ibt-platform/](https://sanghoo11-anthony.github.io/topik-ibt-platform/)
- **📦 GitHub 저장소**: [https://github.com/sanghoo11-anthony/topik-ibt-platform](https://github.com/sanghoo11-anthony/topik-ibt-platform)

## 주요 기능

1. **1~6급 목표 급수별 맞춤 실전 IBT 모의고사**
   - TOPIK I (1~2급 듣기·읽기) 및 TOPIK II (3~6급 듣기·읽기·쓰기 51~54번) 실전 기출 유형 문항 수록
   - 좌측 지문·듣기 대본 / 우측 문항 5:5 IBT 표준 분할 화면 및 실시간 타이머 지원
2. **12개 국어 UI·해설 번역 및 다국어 음성(TTS) 듣기**
   - 한국어, 영어, 베트남어, 중국어, 일본어, 스페인어, 프랑스어, 러시아어, 인도네시아어, 태국어, 몽골어, 아랍어 지원
   - 각 국가의 이용자가 해설을 자국어로 읽고 원어민 음성(TTS)으로도 즉시 청취 가능
3. **클릭형 형태소 어휘 툴팁 사전 & 급수별 필수 단어장**
   - 지문 내 어절 클릭 시 기본형(Lemma) 분석, 한국어 풀이, 다국어 번역, 발음·해설 음성 재생 제공
4. **TOPIK II 쓰기(51~54번) 인터랙티브 원고지 에디터 & AI 첨삭 리포트**
   - 200자·300자·700자 원고지 실시간 글자 수 카운터 및 모범 답안 비교/자동 채점
5. **TOPIK 종합 학습 자료실**
   - 추천 유튜브 특강 채널, 급수별 핵심 문법(1~6급), 최빈출 관용어·사자성어 사전 수록
